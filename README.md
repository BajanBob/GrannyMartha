# Granny Martha

A tutor app for Key Stage 3 pupils building towards GCSEs: Maths, English, Geography, RE and History.

- Android: the app from the latest release (GrannyMartha.apk).
- iPhone / iPad: open the web version in Safari, tap Share, then Add to Home Screen.

`index.html` is the web version; `src/` is wrapped as the Android app.
